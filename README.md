# Obsidian Plugin: Auto Collapse Sidebars

Плагин для Obsidian на TypeScript, который автоматически сворачивает обе боковые панели при входе в заметку с определённым тегом (по умолчанию `#zen`) и разворачивает их обратно при переходе к обычным заметкам.

## Особенности
1. **Умное состояние**: Разворачивает при выходе из заметки только те панели, которые были свернуты плагином автоматически (если вы свернули панель сами заранее, плагин не будет открывать её принудительно).
2. **Свобода ручного управления**: Если плагин свернул панели, но вам срочно понадобилось открыть их вручную — вы можете спокойно это сделать. При закрытии вкладки или переходе на другую заметку панели штатно восстановятся.
3. **Поддержка тегов**: Распознает тег как в теле заметки (`#zen`, `#zen/subtag`), так и в блоке свойств YAML frontmatter (`tags: [zen]`).
4. **Гибкие настройки**: В меню настроек Obsidian можно изменить имя тега-триггера, а также выбрать, какие именно панели сворачивать (левую, правую или обе).

## Сборка из исходников

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка плагина в папку dist/
npm run build
```

## Установка в Obsidian

После сборки скопируйте содержимое папки `dist/` (`manifest.json`, `main.js`, `styles.css` при наличии) в папку плагина вашего хранилища:
`ВашVault/.obsidian/plugins/obsidian-auto-collapse-sidebars/`

Затем в Obsidian: **Настройки** -> **Сторонние плагины** -> обновите список и включите **Auto Collapse Sidebars**.
